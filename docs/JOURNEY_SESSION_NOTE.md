# Journey 세션 노트 — 마크업 개념 (1단계)

> Journey 섹션 **마크업 단계**를 직접 손코딩하며 짚은 개념 정리. 클로드코드를 껐다 켜도 다시 볼 수 있게 남긴 노트.
> 확정 스펙·인터랙션·콘텐츠는 `SECTION_JOURNEY_PLAN.md`, 여기는 **"마크업을 왜/어떻게"** 만 담는다.

---

## 전체 뼈대

의미(시맨틱)를 먼저 맞추고, 위치·선 그리기는 이후 단계로 미룬다.

```
<section id="journey">        ← 앵커 + container-page
  <span>// JOURNEY</span>     ← 라벨(장식성 텍스트)
  <h2>여기까지 걸어온 길</h2>   ← 섹션 제목(한글 → font-korean)
  <div> (타임라인 래퍼)
    <svg aria-hidden>…</svg>   ← 스파인 선(장식)
    <ol>                       ← 마일스톤(순서 있음)
      <li> 연도 · 제목 · 설명 </li> × 4
    </ol>
  </div>
</section>
```

---

## `<ol>` 타임라인 시맨틱

- 타임라인은 **순서(시간 순)가 의미**다 → `<div>` 나열이 아니라 **`<ol>`**(스크린리더가 "목록, N개 항목"으로 순서를 전달). 각 마일스톤 = `<li>`.
- **제목은 `<h3>` 권장**: 섹션 제목이 `<h2>`니, 마일스톤 제목을 `<h3>`로 두면 헤딩 계층(h2 → h3들)이 생겨 목차 이동이 가능하다. (원치 않으면 `<p>`/`<span>`도 가능 — 선택.)
- **연도는 `<time>` 쓰지 말 것**: `<time datetime>`은 **실제 기계 판독 날짜**를 뜻하는데, 우리 연도는 **허수(3000년대)** 라 거짓 정보가 된다 → **평범한 `<span>`**.
- **반복 데이터는 배열 → map**: `[{ year, title, desc }, …]` 하나 만들어 `.map`으로 `<li>` 렌더(컨벤션·유지보수).

## SVG `<path>` 정적 스파인 — 선 그리기 원리

- **`<line>`이 아니라 `<path>`** 를 쓰는 이유: 3단계에서 framer **`pathLength`(선 그리기 애니메이션)** 가 `<path>`에서 가장 자연스럽다(지금은 정적, 자리만).
- **`d`(경로 명령) 기초**:
  - `M x y` = **moveto** (펜을 그 좌표로, 시작점)
  - `L x y` = **lineto** (직선으로 이동)
  - `V y` = **vertical lineto** (세로로만)
- 세로 스파인 예(개념):
  ```html
  <svg viewBox="0 0 4 480" aria-hidden fill="none">
    <path d="M 2 0 V 480" stroke="currentColor" stroke-width="2" />
  </svg>
  ```
  - **`fill="none"` + `stroke`** 가 핵심 — 선은 채움(fill)이 아니라 **테두리(stroke)** 로 그린다. `stroke-width`로 두께.
  - 색은 **`currentColor`** 로 두고 부모에 `text-accent` 토큰 → 하드코딩 없이 상속(아이콘 규칙과 동일).
  - **`aria-hidden`** — 장식이라 스크린리더 제외.
  - **`viewBox`** = 내부 좌표계. 실제 크기는 CSS(`w`/`h`), 내부 좌표는 viewBox — **둘을 분리**해서 생각.
- **3단계 대비**: `pathLength`는 내부적으로 `stroke-dasharray`로 "얼마나 그려졌나"를 조절한다. 지금은 선을 **통째로(정적)** 그려두면 그게 곧 정지 최종형이 된다.

## 노드 점 · 카드 배치

- **선은 SVG, 카드(텍스트)는 HTML** 로 분리한다(텍스트 접근성·선택 유지).
- 노드 점은 SVG `<circle>` 또는 HTML 점(`rounded-full`) 둘 다 가능 — 장식이라 어느 쪽이든 OK. (스타일 단계에선 HTML 점이 다루기 쉬움.)
- 실제 선-점-카드 **정렬은 스타일(2단계)** 의 몫. 마크업 단계는 **DOM 구조·의미**만 잡는다.

## 관통 원칙 — "정지 최종형 완결"

모션을 하나도 안 켠 상태(마크업만)에서 **선 다 그려짐 + 노드 다 보임 + 연도·제목·설명 다 읽힘**이 되어야 한다. 이게 곧 reduced-motion·SSR·no-JS의 기본형이다(`SECTION_JOURNEY_PLAN.md` §5).
